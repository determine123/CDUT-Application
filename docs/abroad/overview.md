# 境外申请：项目、文书与预算

> 整理：2026-10-03。通用建议、个人经历与政策分开阅读；当年官方文件优先。

当前尚无经确认的成理境外录取案例，以下是准备清单，不提供签证或移民政策结论。

区分授课型硕士、研究型硕士和博士，比较课程、研究、毕业要求、语言、推荐信与资金。每个项目回官方页面核对，旧案例用于理解过程。

预算涵盖考试、申请、学费、生活、保险和交通，注明币种与付款节点。奖学金“可申请”不等于一定获得，条件不明时问项目方。

文书围绕真实行动与证据，不拼接模板。委托服务要明确交付、退款和账号控制，不能伪造材料。录取后依官方来源安排入学手续，公开分享可模糊成绩和经济背景。

## 为每个项目保存一份独立要求

同一大学不同项目的条件可能不同。以项目当前申请周期的官方说明为起点，记录页面更新时间和自己查看的日期；区分必交、可选、录取后补交和针对特定背景才适用的材料。页面没有写清楚时，向项目负责渠道提问，不把别的项目要求直接移过来。

```text
大学 / 项目正式名称 / 学位类型：
申请周期与计划入学时间：
官方项目页、申请说明及查看日期：
申请资格与尚待核实的条件：
截止时间原文、时区、对应北京时间：
成绩单、学历或在读证明的要求：
语言或其他考试要求、成绩提交方式：
文书题目、篇幅与文件格式：
推荐信数量、提交方式及独立截止时间：
其他必交或可选材料：
申请费、资助信息及官方来源：
已提交内容、版本、回执与待完成事项：
```

截止日期只有日期而没有时间或时区时，先核实，不自行推断是北京时间当天午夜。推荐信、考试成绩或补充材料可能有独立节点，分别记录；自己点击提交后仍需查看系统是否有缺件提示。完成缴费、提交申请和材料审核完成是不同状态。

## 怎样准备推荐信协作

选择确实了解自己课程、研究或项目工作的人，提前说明申请目标、需要的材料、提交方式和期限，先确认对方愿意推荐。可提供一页背景、真实合作任务、成果链接和项目列表，帮助推荐人回忆具体事实，不提供虚构评价或未经确认的成绩。

逐个核对系统中的姓名、职务与联系信息，并确认推荐邀请是否发出、系统是否显示提交完成。对方尚未收到邀请时，按官方说明检查邮箱或联系项目方；跟进时附上项目与期限，避免仅说“老师还没交”。有项目允许申请人上传、也有要求推荐人独立提交的情况，按对应规则处理，不代登录推荐人的账号。

推荐信内容、邮箱和私人沟通不作为公开投稿附件；分享经验可以说明准备过程与时间安排。不要将推荐人同意帮助误写成对方保证录取。

## 文书用真实经历回答题目

先拆出题目实际要求，例如研究兴趣、已有准备、选择项目的原因或职业目标，再选择能支持回答的经历。同一段项目经历，应能说明问题、本人动作、结果和局限，而不是只列工具名称。

关于项目的理由来自当前官方课程、研究方向或培养说明，并与自己的准备连接。申请不同项目时核对名称和题目，不仅替换校名；专业兴趣尚不明确时，写实际探索与待解决的问题，不编造长期研究经历。简历、文书与申请表中的专业、年份、职责和结果阶段保持一致。

提交前检查篇幅、格式和文件是否完整，把本次版本与提交记录一起保存。允许他人或工具协助修改时仍须符合项目要求，并由自己确认事实、表达和最终内容；不上传含他人隐私或未获公开许可的项目资料。

## 收到结果后继续核实条件

把结果阶段、接受期限、尚待满足的条件和后续手续写进记录。资助是否已确认、课程或指导安排是否已落实，分别依据对应文件核实，不仅依据宣传介绍。比较多个机会可参考[录取决策方法](../planning/decision-review.md)，材料管理参考[申请材料核对](../planning/materials.md)。

若愿意投稿，写清申请年份、当时背景、准备过程、实际结果与未能核实的部分。项目要求、费用和个人体验分开标注；目前本册仍没有经确认的成理境外录取亲历案例，不以通用清单冒充案例。
