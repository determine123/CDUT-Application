# 本科到研究生的过渡

> 整理：2026-10-03。通用建议、个人经历与政策分开阅读；当年官方文件优先。

录取后分别处理毕业、学历、档案、入学材料与课程，目标学校当年通知为依据。降级后调整毕业时间，更需要确认文件完成节点。

## 将两所学校的手续分开跟进

本科毕业与研究生入学由不同主体办理。先分别保存本科院校的毕业离校通知、招生单位的录取及新生通知，再把通知中的事项按负责单位排序。不要把同学上一届的清单当成今年必须提交的材料。

- **本科毕业与学位**：核对课程、毕业设计及其他培养要求的审核状态，确认相关证明何时可取得。完成答辩、提交材料与通过最终审核分开记录。涉及调整毕业年份的情况，向本科院校负责岗位核实正式记录与预计完成时间。
- **入学资格与材料**：逐项核对新生通知的材料名称、提交渠道、截止时间和原件查验安排。证明暂时无法取得时，提前向招生单位说明情况，询问是否存在正式替代或补交办法；不要自行假定可以延期。
- **档案事项**：按接收单位的正式要求确认接收信息、办理主体及寄送或转接流程。把申请转出、实际发出、接收确认分成不同状态，保存可查询的回执；不凭个人经验建议自行拆封或处理档案。
- **离校与报到**：把住宿、借阅归还及其他离校事项与研究生报到日程分别记录，避免把某一手续完成等同于所有事项完成。交通和住宿安排以确认过的校区、报到地点和入住宿舍信息为依据。

没有出现在适用通知中的事项，先询问是否需要办理，而不是额外收集一整套敏感材料。公开分享经验时，仅说明流程与材料类别，不上传完整通知书、证件、档案标签或含私人信息的回执。

## 一份过渡事项记录

可复制到自己的笔记，为每个事项填写一条。完整通知与回执保存在个人文件夹中，不提交到本手册仓库。

```text
事项：
本科院校 / 研究生院校负责部门：
适用通知标题、日期与网址：
需提交的材料及版本：
办理方式和截止时间：
当前状态：待核实 / 待办理 / 已提交 / 待补正 / 已确认完成
提交日期与回执：
结果查询渠道：
仍缺什么、由谁处理：
下一次跟进日期：
完成依据：
```

例如，档案转接记录中写“已申请转出”时，仍需按办理说明查询是否发出及是否接收；记录中写“已提交入学材料”时，仍需检查是否有审核或补正提示。若不同通知的日期或要求看起来冲突，保存两份文件并向负责部门核实，避免自行挑选较宽松的一项。

入学前和导师沟通可完成的准备任务，了解团队指导、资源和去向。不要只根据网络上的学校评价作判断。

## 入学前的学习准备怎样设边界

先询问课程基础、阅读材料、必要工具和可完成的小任务，再决定暑期投入。把任务写成能交付的结果，例如一页文献梳理、能运行的示例或一次实验复现；说明自己的当前基础与可投入时间，避免只承诺“随时可以做”。

向团队确认数据、代码和设备的使用范围。尚未获准公开的材料不放进个人公开仓库；需要付费工具、采购或大额投入时，先确认是否必要及由谁负责。暑期准备情况不能代替正式入学、资助或团队安排的确认。

## 第一个月的检查点

核对培养要求和选课安排，记录自己缺少的先修基础；确认团队讨论、任务反馈及资源申请的渠道。第一次汇报可按“已完成什么、证据在哪里、当前卡点、尝试过什么、希望确认哪件事、下一步计划”组织。

每周保留简短进展记录，包括失败尝试和原因。一个任务连续没有进展时，带着具体复现步骤或问题向指导者求助，重新确认任务范围，不用堆积工时替代沟通。个人计划应给课程、休息和必要手续留出时间；一个团队的安排不能推广成所有研究生的日常。

研究生学习需要面对不确定结果，用课程和具体任务重新评估基础。讨论带进展、问题和下一步，比单纯累计工时更有效。

实习与课程、科研和导师安排一起确认；自己或某组的安排不代表全校制度。
