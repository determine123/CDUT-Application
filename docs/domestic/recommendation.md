# 推免、夏令营与预推免

> 整理：2026-10-03。通用建议、个人经历与政策分开阅读；当年官方文件优先。

本科院校推荐资格与目标单位接收是两个环节。参加活动或收到某种通知不等于正式录取。

原学校一侧查当年学校和学院推荐办法：资格、成绩范围、材料、名额和公示申诉。转专业或提前毕业的适用规则要明确咨询，不能推断。

目标单位一侧查报名和接收条件，准备成绩、研究兴趣与真实项目。导师回复不能替代正式程序。保存申请、面试与通知答复节点，并阅读承诺和确认要求。

[全国推免服务系统](https://yz.chsi.com.cn/tm/)为对应服务入口。本册没有核实当届成理推荐门槛，也不把成理接收研究生的通知当成本科推荐办法。
