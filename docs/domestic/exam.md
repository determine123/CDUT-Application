# 考研：选校、备考与复试

> 整理：2026-10-03。通用建议、个人经历与政策分开阅读；当年官方文件优先。

目标学院当年的章程、目录、大纲与复试办法是核对依据。作者考研进入上交，但尚未提供具体分数、科目和复试细节，本册不编写所谓独家题库。

选校核对专业代码、学硕或专硕、学习方式、报考资格、考试科目、培养方向与费用。计划数与最终录取人数可能不同，不只用最低分判断难度。

备考先做诊断练习，再按周记录基础缺口和错误类型。课程与考试准备冲突时保证毕业所需；培训信息回到官方文件核对。

复试准备真实项目、专业基础与表达，按当年要求准备材料。录取、调剂和确认操作遵循当年规定，不编造实验或奖项。

[研招网](https://yz.chsi.com.cn/)是重要入口；[成理研究生院](https://gra.cdut.edu.cn/)只代表本校招生，不能替代上交或其他目标单位文件。

## 2027 年考试报名：已核实的年度信息

核查日期：2026-10-04。本段只适用于 2027 年全国硕士研究生招生考试，后续年份须重新查公告。

根据研招网 2026-09-27 发布的[2027 年考试公告](https://yz.chsi.com.cn/kyzx/other/202609/20260927/2293973606.html)，网上报名为 **2026-10-15 至 2026-10-24，每日 09:00–22:00**；预报名为 **2026-10-09 至 2026-10-12**，具体安排另看省级教育招生考试机构公告。

公告要求按省级机构、报考点和招生单位的规定填报、交费及提交核验材料，并关注审核结论。不要仅凭报名号判断全部手续已完成；材料补充和审核要求需回到本人报考点公告核对。[网上报名入口](https://yz.chsi.com.cn/yzwb/)可用于操作，年度安排以正式公告为依据。

报名信息填报后仍需自己逐项核对。公告说明确认后的报名信息不再修改；不要等截止日才发现身份、专业或报考点有误。手册不代操作账号，也不收集报名资料。

完整资格与考试规定见[2027 年招生工作管理规定](https://yz.chsi.com.cn/kyzx/jybzc/202609/20260924/2293971511.html)。本段未核实每位读者所在省份或报考点的材料细则，也不据此承诺个人报考资格。

## 读招生目录时逐项核对

先在[研招网硕士专业目录](https://yz.chsi.com.cn/zsml/index.htm)定位方向，再打开目标单位当年的完整目录和章程。目录系统说明数据由招生单位上报，有疑问应向对应单位咨询。

把目标记到具体的“年份—招生单位—学院—专业代码—方向—学习方式”，不只保存一个专业名称。同名方向可能在不同学院；不要把某学院的科目或资格要求套到另一个学院。

1. 核对专业代码和名称，以及学术学位或专业学位、全日制或非全日制等属性。
2. 保存当年各科代码与名称；某个科目是否自命题、是否有替代选项，由目录和说明确认。
3. 查看限制、备注和附件，记录需要向招生单位确认的问题。
4. 对照当年考试大纲或参考说明，再决定复习资料；旧书单先检查科目是否一致。
5. 区分计划、推免相关口径和实际录取结果。没有文件解释时，不自己推算一个确定的统考名额。

以上是核对方法，不是任何学校的固定招生条件。资料尚未公布时，往年信息只能用于暂时了解，记录为“待当年文件确认”。

## 报考点与招生单位分别核对

招生单位是希望进入的学校或机构，报考点负责相应报名核验与考试组织事项，二者不能混为一谈。目录里找到目标专业，并不等于已经确定自己可以选择哪个报考点。

具体选择依据本人身份和所在地要求确认。转专业、调整毕业时间或学籍信息有变化时，先核对学信网记录与本人正式学籍情况；不能因为曾经降级就自行认定某种报名身份。

## 留下一条核查记录

为每份重要文件保存标题、发布单位、发布日期、适用招生年份、链接和自己查看的时间，并写清它回答了什么问题。不同年份或单位的材料冲突时，回到适用文件和官方咨询，不用培训截图投票决定。

为未解决事项写具体问题，例如：“当年某学院某代码专业是否接受我的背景？目录备注中的条件适用哪一类考生？”提出问题时提供必要背景即可，不在公共 issue 上传证件、学号或完整报名表。
