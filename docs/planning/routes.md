# 升学与就业：主方案与备用方案

> 整理：2026-10-03。通用建议、个人经历与政策分开阅读；当年官方文件优先。

先明确你想做的工作、需要的训练、可承受的时间与支出，再比较考研、推免、境外申请和就业。没有对所有人最优的路线。

每个方案记录资格、关键节点、材料、费用、能力缺口与备用安排。先核实不能错过的节点，再分配每天做什么。探索可以并行，但不必在所有路径上无差别投入。

案例要结合专业、年份、课程、项目与支持条件阅读。过去上岸不能推导当前概率，缺少渠道的案例不能当完整路线图。失败和转向同样值得记录。

作者是考研进入上交，不应将其案例归入推免。其他渠道的章节提供准备方法，等待不同背景同学真实投稿。
