# 准备时间线与材料账本

> 整理：2026-10-03。通用建议、个人经历与政策分开阅读；当年官方文件优先。

从目标年份官方通知倒排，不使用固定的“所有学校截止日期”。账本记录事项、截止时间、官方链接、当前状态和备用安排。

较早阶段核对毕业时间和目标资格，保存成绩、项目与学习记录。申请前按清单办理证明、简历、作品及需要的推荐材料；推荐人应真实了解自己，不伪造签名或关系。

提交期确认姓名、专业、文件与联系方式，保存回执，对复试和通知答复设置提醒。结果出来后区分提交、面试、拟录取、正式录取，安排毕业、档案和入学事项。

每月复盘一次信息变化与准备进度。公开账本时删除学号、身份证、系统账号、私人联系方式和未经许可的通知截图。
