# 申请材料核对与公开分享边界

> 通用方法，整理于 2026-10-03；具体校内政策另行核查。

材料准备尽量从官方清单逐项开始。不同路径可能需要成绩、在读/毕业证明、语言、作品、推荐信或科研说明，不要求每人准备同一套。

## 提交前核对
姓名、证件信息、学校、专业、年份与正式记录一致；文件可打开、页数完整、盖章和翻译按要求处理。提交后保存版本与回执，更新材料时确认系统是否允许替换。

推荐人和项目指导者应真实了解自己。引用团队项目时写个人职责，论文区分投稿、接收与发表。没有最终结果不能写成录取或发表。

## 分享时保留什么
公开经验侧重流程、决策、限制与复盘。精确成绩、姓名、导师联系方式和家庭信息可省略或用区间；隐私缺失不会让经历失去价值。

## 不应公开什么
身份证、学生证、完整成绩单原件、账户、通知中私人联系方式和未经许可的聊天。照片或 PDF 还可能包含隐藏信息，发布前检查，不只遮一行文字。

手册不收集申请账号或证件原件，投稿仅提交作者愿意公开且有权公开的文字。
