# 投稿模板

复制下列结构，按真实信息填写；不适用项可说明或省略。

```markdown
# 文章标题
作者：可用昵称
整理日期：YYYY-MM-DD
经历时间：年份/学期
适用背景：校区、年级、专业、申请年份或岗位
性质：个人经历 / 通用建议 / 政策核查

## 背景与目标
## 过程、个人行动与关键选择
## 结果、失败与局限
## 给类似背景同学的建议
## 来源与适用年份
```

申请案例区分提交、面试、拟录取和正式录取；政策记录文件和条款；课程记录学期、代码与考核方式。可以模糊精确成绩和身份，不公开家庭细节、证件和联系方式。

## 考研经历：把选择和调整写清楚

以下是待填写结构，不是已经发生的案例。所有方括号内容由作者填写或删除。分数、排名及目标导师均可不公开；省略时仍可讲清准备过程。

```markdown
# [昵称]：[申请年份]考研经历

- 整理日期：[YYYY-MM-DD]
- 本科背景：[专业方向、毕业届别；校区可选]
- 目标：[学校、学院和专业；按本人愿意公开的范围填写]
- 结果阶段：[备考中 / 已报考 / 已参加初试 / 已参加复试 / 拟录取 / 正式录取 / 转向]
- 公开范围：[昵称署名或匿名；不公开的信息]

## 为什么选择这个目标
当时比较过哪些方向？最看重什么？有哪些时间、基础或经济约束？
哪些判断来自当年官方信息，哪些是个人判断？

## 科目核对与起点
实际准备了哪些科目？参考的是哪一年的招生目录和大纲？
开始时怎样判断自己的基础？不要把目标专业名称当作考试科目的证据。

## 准备过程与调整
按阶段写代表任务、检查方法和一次具体调整。
例如：某类题反复出错后，怎样定位问题、改练习、再次检查？
同时有课程、实习或毕设时，怎样安排冲突？

## 复试、调剂或转向
只写本人实际经历；没有参加的环节标注“不适用”。
区分正式通知和个人推测，不公开禁止传播的试题或私人聊天。

## 结果与复盘
结果在哪个阶段确认？哪些行动有帮助，哪些尝试没有效果？
如果重新准备，会调整什么？哪些条件使经验不适合直接照搬？

## 来源和更新
附使用过的官方文件标题、年份与链接；无公开链接可说明原因。
结果发生变化时，更新日期和阶段，而不是保留过时的“已录取”。
```

## 推免经历：分开推荐资格与接收过程

```markdown
# [昵称]：[申请年份]推免经历

- 整理日期：[YYYY-MM-DD]
- 本科背景：[专业方向、毕业届别；可模糊成绩]
- 结果阶段：[准备中 / 获得本科推荐资格 / 接收考核中 / 待录取确认 / 正式录取 / 转向]
- 公开范围：[署名方式和不公开的信息]

## 本科推荐资格
按本人经历写清当年的流程和时间，不把个人成绩写成全校统一门槛。
资格是否已经确认？依据是哪一年的公开通知？

## 目标单位接收
分别记录实际参加的夏令营、预推免或正式系统环节。
哪些结果只是入营、考核结果或意向，哪些已进入正式确认？
不适用的环节直接省略，不把几个阶段合并为“保研成功”。

## 材料与交流准备
实际展示了哪些课程、项目或研究工作？本人承担什么？
如何解释尚未完成的成果，怎样核对提交文件？

## 多个选择与最后决定
当时有哪些约束，怎样比较培养内容、方向和生活成本？
写清自己的权衡，不替其他同学作相同决定。

## 结果、失误与建议
以本人确认的阶段描述结果，写一项可改进之处。
附当年来源，并说明本例不能推导其他年份或学院的资格要求。
```

## 境外申请、就业与其他出路

沿用通用模板，但补充路径特有的信息：境外申请写项目名称、申请轮次、语言或材料要求的年份，以及预算中实际承担的部分；就业写岗位方向、申请渠道、本人完成的项目与面试阶段。收到口头意向、书面 offer 和正式入职应分别描述。

不愿公开学校、企业或具体金额时，可以用方向、地区或区间说明。不要为了使文章“完整”填入未经历的环节。

## 求职经历：记录岗位匹配与实际反馈

下面是填写提纲，不是作者已经获得的 offer 或已发生的面试。可以只写一次有代表性的申请，不需要公开企业名称、面试官身份、薪酬或完整简历。未收到 offer 的经历也可以投稿。

```markdown
# [昵称]：[毕业届别或求职年份]求职经历

- 整理日期：[YYYY-MM-DD]
- 本科背景：[专业方向、毕业届别；按愿意公开的范围填写]
- 目标岗位：[方向和工作内容；企业、地区可模糊]
- 申请类型：[实习 / 校招 / 其他；说明适用背景]
- 结果阶段：[准备中 / 已投递 / 面试中 / 未通过 / 主动退出 / 口头意向 / 书面 offer / 已入职]
- 公开范围：[昵称、可保留的信息、不公开的信息]

## 从岗位要求发现了什么差距
当时阅读的岗位信息是什么时间的？哪些能力能用课程、项目或实习证明？
哪些是尚未具备的条件，怎样决定是否继续申请？
不把一份岗位描述扩写成整个行业或所有公司的共同门槛。

## 本人做了哪些准备
选一项代表任务，写清起点、自己的动作、可验证结果和限制。
团队项目写自己的职责；公开仓库、课程成果或实习材料只附有权分享的部分。
如果临时补学了某项技术，怎样检查自己能够独立使用？

## 投递与面试过程
通过什么渠道投递，实际经历了哪些阶段？未经历的阶段标“不适用”。
可以写题目类别、考查能力、自己的卡点和事后练习方式；
不公开保密题目、录音、内部材料或未获许可的聊天截图。
收到的明确反馈与自己对拒绝原因的推测分别说明。

## 结果与选择
结果在哪一天或哪个阶段确认？附带条件是否仍待本人确认？
如果选择退出或比较多个机会，主要约束是什么？
书面 offer、签署材料和实际入职分别记录，不把其中一个阶段替代其他阶段。
不愿公开金额时可说明预算约束或考虑因素，不必填具体数字。

## 复盘与适用边界
最有帮助的一项准备是什么？哪次投入没有产生预期效果？
若重新申请，会改变什么，怎样判断改变是否有效？
哪些经验依赖当时的专业基础、时间、地点或招聘安排，不能直接照搬？

## 来源与更新
公开岗位信息能否提供来源和查看日期？已失效时说明实际读到的范围。
私人反馈不要求提供截图；只整理本人获准分享的内容。
后续状态变化时更新结果阶段及整理日期，保留必要说明。
```

写作前可参考[项目证据整理](../career/project-proof.md)和[面试准备](../career/interview.md)。投稿中的结果由作者按实际情况描述，模板本身不证明录用，也不要求提交身份证明或企业内部材料。涉及合同条款或手续的问题，应另向对应负责主体核实，不以个人经历代替办理依据。

## 发布前自查

- 作者本人核对过文字；代整理者说明整理方式，引用他人经历获得本人同意。
- 已确认署名和公开范围；具体年份、专业、排名、导师等组合也可能识别身份，必要时进一步模糊。
- 已删除模板占位项，未确认的内容标为“待核实”，没有用推测补足结果。
- 原创文字的公开许可已确认；引用图片、聊天或材料另行核对授权，不能用统一许可覆盖第三方材料。
- 文件中没有证件、学号、账号、访问令牌、私人联系方式或未授权聊天。

使用[投稿流程](index.md)提交；需要先口述整理，可参考[访谈问题](interview.md)。
